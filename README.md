# Kalkulator-Sederhana-UAS
Aplikasi java ini dikembangkan untuk memenuhi project UAS mata kuliah pemograman java. 

Pada aplikasi kalkulator ini, file teks history_db.txt digunakan sebagai database sederhana untuk menyimpan riwayat perhitungan.
Setiap kali pengguna melakukan perhitungan, hasilnya disimpan ke dalam file tersebut.
Ketika aplikasi dijalankan kembali, data dari file dibaca dan ditampilkan sehingga riwayat tetap tersedia meskipun aplikasi ditutup.
